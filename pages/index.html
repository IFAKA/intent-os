01 / The authoring surface

Less mechanism.
More meaning.

Application code stays close to the thing you are building. IntentOS turns a small declarative page into server-rendered HTML backed by validated, transactional domain behavior.

Explore the model ↗
<x-list of="Product" as="p">
  <article>
    <h2>{{p.name}}</h2>
    <x-money value="{{p.price}}" />
    <button data-action="cart.add({{p.id}})">
      Add to cart
    </button>
  </article>
</x-list>
02 / What the runtime owns

A dependable center
for agent-built apps.

↯

Server authority

Prices, inventory, sessions, orders, and payment state stay on the trusted side of the boundary.

⌁

Native surfaces

Semantic HTML works without JavaScript, then gets enhanced with targeted fragments when it is available.

◌

Inspectable systems

Schema generation, migrations, request traces, tests, and ownership boundaries stay visible to the team.
