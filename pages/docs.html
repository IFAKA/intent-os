01 / First contact

From zero to a working app in three moves.

Everything below works locally with the repository as it stands today. No account provider or payment account is required to explore the runtime.

01

Install the runtime

Clone the project, install dependencies, and verify the framework before an agent touches the app.

npm install\nnpm test
02

Make a starter app

The generator creates only application-owned files and leaves existing work untouched.

npx intent-os create my-store\ncd my-store\nnpx intent-os dev
03

Shape the surface

Edit the files agents can understand at a glance. The runtime supplies the authority behind them.

pages/\nschema.js\napp.config.js\ntheme.css\nsrc/

03 / Know the terrain

The project has a clear ownership boundary.

my-store/├─ pages/ your routes├─ src/ your data├─ public/ your browser assets├─ schema.js your data model├─ app.config.js your runtime intent└─ theme.css your visual language
Framework-owned

Authority is not scattered across the app.

Routing, server actions, validation, CSRF, sessions, SQLite access, inventory, orders, and payment adapters live under framework/. That gives agents a stable contract to build against.
